# Menadżer wydatków firmy

## Autorzy
Tomasz Kornaś
Bartłomiej Leś

## Cel aplikacji

Aplikacja umożliwia zarządzanie wydatkami firmy. Pracownicy dodają wydatki, a administrator je kontroluje i zatwierdza.

## Planowane funkcje
- Rejestracja i logowanie.
- Dodawanie, edytowanie i usuwanie wydatków.
- Zatwierdzanie wydatków przez administratora.
- Statystyki i wykresy wydatków.
- Kontrola budżetu firmy.

## Technologie i dane
- React
- Node.js + Express
- MongoDB
- Tailwind CSS

## Zagrożenia i zabezpieczenia
- Dostęp do cudzych wydatków – kontrola uprawnień.
- Nieprawidłowe dane – walidacja po stronie serwera.
- Nieuprawniony dostęp do panelu admina – system ról.
- Ataki XSS – bezpieczne wyświetlanie danych.
- Kradzież haseł – haszowanie haseł.
